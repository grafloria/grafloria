Square inside square: a widget, and a container that holds widgets

The same board holds two different kinds of tile. One is a widget. The other is a group with a whole second board inside it, locked in place from the outside. Everything that feels "built from scratch" follows from that lock.

"A widget carrying widgets is a CONTAINER: it mounts as a member group (a locked slab in its parent's grid, exactly like a view's board one level down) with its own nested pack grid bound on it."dashboard.ts, the option's own doc comment
