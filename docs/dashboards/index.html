Grafloria Dashboards

The JavaScript dashboard layout library with undo, nesting and a splitter layout

Grafloria Dashboards is an MIT JavaScript dashboard layout library: draggable, resizable widgets on a grid or a splitter layout, with undo, nesting and persistence built in, for Angular, React, Vue or plain JavaScript.

Two layouts, one document

The grid

Twelve columns, spans and rows, push-down re-packing with a truthful placeholder — the gridstack model, with fluid width by default so widgets lay out in real CSS pixels rather than a scaled picture. sizing: 'grow' extends the board; 'fit' keeps the height and never scrolls.

The splitter

layout: 'split' is the way BI dashboard designers align widgets: one widget fills the surface, the next halves it, dividers are percentages you drag, a drop lands on an edge or under a whole row. setLayout() switches live and keeps the picture; toJSON() saves either one.

Built in, not DIY

Fluid or fixed

No width → the board is 100% of its container at zoom 1. An authored width keeps a framed world for a board inside a larger diagram.

Fit never scrolls

The container height is a capacity. A full board refuses one more row, visibly, instead of painting past its edge.

Drag by caption or grip

dragHandle: the caption strip, your own element, or a painted grip that only the selected widget shows.

Containers

A widget carrying widgets is a section with its own grid; drag across the boundary and the other grid adopts the tile live.

One undo per gesture

Every drag, resize, add or divider move is one command. ⌘Z restores the whole gesture, across containers.

The whole board persists

toJSON() writes widgets, nesting, data, layout and the split tree. Feed it back and the board is the same board.

Keyboard and screen reader

Roving tab stop, spoken labels per tile, arrows move, Shift+arrows resize or move a divider. axe-core in CI.

Export

SVG, PNG and PDF, client and server side — the same engine that exports diagrams exports the board.

Bring your charts

The kit never picks a charting library. renderWidget hands you the widget and a raw element; six built-in kinds (KPI, line, bar, donut, funnel, table) cover the moment you have none.

board.js
import { render, dashboard } from '@grafloria/dashboard';

const spec = dashboard({
  columns: 12, sizing: 'fit', dragHandle: true,
  widgets: [
    { id: 'rev',   kind: 'kpi',  span: 3, data: { label: 'Revenue', value: '$6.8M', delta: 12.4 } },
    { id: 'trend', kind: 'line', span: 9, rows: 2, title: 'Revenue vs target', data: { /* series */ } },
    { id: 'sales', kind: 'echarts', span: 12, rows: 2 },   // your kind…
  ],
  renderWidget: (w, el) => { if (w.kind === 'echarts') mountMyChart(el, w.data); },   // …your renderer
});
render(spec, document.getElementById('board'));
spec.handle.setLayout('split');           // live
const saved = spec.handle.toJSON();         // the whole board

Where it stops

This is a layout and editing library, not a BI suite: no data sources, no query builder, no scheduled reports. Where a BI designer's widget alignment comes up, it is the splitter surface the split layout reproduces, nothing more. Questions people ask

Is Grafloria Dashboards a gridstack alternative?

Yes for the layout: draggable, resizable widgets on a responsive grid with push-down re-packing. It adds what a layout engine leaves to you: undo per gesture, nested containers, a splitter layout, persistence of the whole board and built-in widget renderers. The honest comparison is on the GridStack alternative page, both columns true.

Does fit mode scroll?

No. Under sizing 'fit' the container height is a capacity: rows squeeze so everything stays on one screen, an add that would need one row too many is refused visibly, and nothing is ever painted past the board's edge. Sizing 'grow' keeps row heights and lets the board extend; the wheel scrolls it.

Can a widget be dragged only by a handle?

Yes. dragHandle: true makes the caption strip the only handle; a selector names your own element; { grip: true, position, placement } paints a grip on the selected widget, left, centre or right, inside the header or as a tab above the card. All of it switches live.

Does it work without React?

Yes. The kit is a plain JavaScript function, dashboard(), rendered into any element. Native components exist for Angular, React and Vue, and a web component for everything else.

Can a dashboard contain a diagram?

Yes. Dashboards and diagrams share one engine and one document format, so a diagram is a widget like any other and the same undo stack covers both.

Is any of it paid?

No. Every feature is MIT licensed; there is no pro tier.
